# 游客注册接口说明

## 注册游客账号

```http
POST /auth/register
Content-Type: application/json
```

请求示例：

```json
{
  "loginName": "tourist001",
  "password": "12345678",
  "displayName": "小明",
  "phone": "13800138000"
}
```

业务规则：

- 该接口无需登录，只用于游客自主注册。
- 登录名长度为 4～50 个字符，密码长度为 6～32 个字符。
- 手机号可以不填写；填写时必须为 11 位大陆手机号格式。
- 登录名和手机号不能与已有账号重复。
- 后端固定设置 `roleCode=TOURIST`、`status=ACTIVE`、`venueId=null`。
- 当前项目继续使用 MD5 保存密码摘要，以便与现有登录逻辑保持一致。
- 注册成功返回 HTTP `201`，游客随后调用 `/auth/login` 获取 JWT。
- 注册不会自动创建参观人，参观人仍通过参观人管理接口维护。
