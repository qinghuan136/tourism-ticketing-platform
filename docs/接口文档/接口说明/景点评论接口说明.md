# 景点评论接口说明

景点评论面向游客展示，当前仅支持一级评论和评论点赞。

## 通用规则

- 评论列表可公开访问；发表评论、点赞和取消点赞要求游客登录。
- 评论内容不能为空，最长 500 个字符。
- 同一游客可以发表多条评论；不要求已购买门票。
- 同一游客只能点赞同一评论一次，重复点赞和重复取消点赞均保持成功。
- 评论列表固定按点赞数量倒序；点赞数相同时按评论 ID 倒序。

## 1. 分页查询景点评论

```http
GET /public/venues/{venueId}/comments?page=1&size=20
```

返回评论ID、评论者展示名、评论内容、点赞数量和创建时间。景点不存在或已停用时返回 `NOT_FOUND`。

## 2. 发表景点评论

```http
POST /tourist/venues/{venueId}/comments
Authorization: Bearer <token>
```

请求体：

```json
{
  "content": "展馆内容丰富，适合亲子游览。"
}
```

后端从 JWT 获取当前游客ID，成功返回 `201 Created` 和评论ID。

## 3. 点赞评论

```http
PUT /tourist/comments/{commentId}/like
Authorization: Bearer <token>
```

首次点赞增加点赞数；重复请求不重复累加。

## 4. 取消点赞

```http
DELETE /tourist/comments/{commentId}/like
Authorization: Bearer <token>
```

删除已有点赞记录时减少点赞数；此前未点赞时直接返回成功。
