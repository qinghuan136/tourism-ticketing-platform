# 景点信息接口说明

对应的 OpenAPI 文件：[venue-openapi.json](../接口json/venue-openapi.json)。

当前 MVP 只提供获取和修改当前运营者所属景点的接口。景点 ID 从 JWT 登录信息中的 `venueId` 获取，不需要前端传递。

## 获取当前景点信息

```http
GET /operator/venue
Authorization: Bearer <token>
```

用于进入“景点信息”页面时加载表单数据，返回以下内容：

- 景点名称
- 运营状态
- 景点地址
- 景点简介
- 封面图片地址
- 景点经纬度（已配置时返回）

只有景点运营者可以访问。运营者未绑定有效景点时返回 `NOT_FOUND`。

## 修改当前景点信息

```http
PUT /operator/venue
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

用于点击页面中的“保存修改”按钮时，一次提交文本字段和封面图片。

请求示例：

```bash
curl -X PUT "http://localhost:8080/operator/venue" \
  -H "Authorization: Bearer <token>" \
  -F "name=海湾科技馆" \
  -F "address=广州市番禺区海湾大道 88 号" \
  -F "description=面向公众开放的综合性科技文化场馆，提供常设展览与主题活动。" \
  -F "status=ENABLED" \
  -F "longitude=113.3245000" \
  -F "latitude=23.1067000" \
  -F "coverImage=@venue-cover.jpg"
```

`coverImage` 为可选的图片文件；没有选择新图片时不传该字段，后端保留原封面。图片保存成功后生成的访问地址通过查询接口的 `coverUrl` 返回。

`longitude` 和 `latitude` 为附近景点功能使用的坐标。经度范围为 `-180 ~ 180`，纬度范围为 `-90 ~ 90`；修改坐标时必须同时填写经纬度，两者应使用与游客定位和高德地理编码结果一致的坐标系。

运营状态取值：

- `ENABLED`：启用
- `DISABLED`：停用

接口只能修改当前运营者所属的景点。参数不合法时返回 `INVALID_REQUEST`，景点不存在时返回 `NOT_FOUND`，名称和地址与已有景点重复时返回 `CONFLICT`。

## MVP 范围

当前不提供景点创建、删除、列表或独立启停接口。封面图片随景点修改接口一起上传，运营状态也随景点资料一起保存。
